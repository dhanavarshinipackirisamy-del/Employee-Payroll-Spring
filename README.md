# Employee Payroll Spring Boot Application

## 📌 Overview
This is a Spring Boot application developed as part of the Employee Payroll App.  
It provides REST APIs to manage employee details like name and salary.

---

## 🚀 Features
- Create Employee
- Get All Employees
- Get Employee by ID
- Update Employee
- Delete Employee

---

## 🛠️ Technologies Used
- Java 17
- Spring Boot
- Spring Web
- Maven
- IntelliJ IDEA
